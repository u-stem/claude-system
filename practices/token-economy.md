# トークン経済の運用

「最小限に保つ」という原則([`principles/01-context-economy.md`](../principles/01-context-economy.md))を、
「**どこをどう抑えれば、どのコストが下がるか**」という因果と、その効果を**計測する手段**まで落とす。
抑制は精神論ではなく、発動点が特定された機構の積み重ねとして扱う。

## 関連する原則

- [`principles/01-context-economy.md`](../principles/01-context-economy.md) — 注意は有限資源、削除は追加と同等の価値
- [`principles/04-progressive-disclosure.md`](../principles/04-progressive-disclosure.md) — 入口は要約、深掘り時のみ全文
- [`principles/05-separation-of-concerns.md`](../principles/05-separation-of-concerns.md) — 境界で閉じる

## いつ使うか(トリガー)

- 大量出力(テスト・ビルド・ログ)がそのまま文脈に流入していると気づいたとき
- 同じ背景・前置きを毎ターン繰り返していると気づいたとき
- セッションが長くなり、完了済みタスクの議論が後続の信号比を下げているとき
- 新しい抑制策を追加する前に、既存の発動点と重複しないか確認したいとき

## 手順

1. **発動点を特定する**: 漠然と「短くする」のではなく、コストが生まれている箇所を 1 つ名指しする(下表の因果一覧を起点にする)。
2. **対応する機構を当てる**: 各発動点には対になる抑制機構がある。原則の宣言ではなく、機構を働かせる。

   | 抑制ポイント | 機構 | 抑えられるコスト |
   |---|---|---|
   | 大量出力タスク | 独立コンテキストへの委譲([`delegation-orchestration.md`](./delegation-orchestration.md)) | メイン文脈の成長 |
   | テスト/ビルドの冗長出力 | 実行前に標準出力を末尾 N 行へ切り詰める(標準エラーと終了コードは保持) | 失敗ログ全文の流入 |
   | 初期入力の肥大 | 段階的開示(入口は要約、必要時のみ全文) | 読まれない情報の常時占有 |
   | 試行錯誤の往復 | 危険・無駄な操作を実行前に弾く | 無効な往復の累積 |
   | 道具定義の常時占有 | 必要な定義だけ遅延取得する | 使わない定義の占有 |
   | 完了タスクの持ち越し | タスク境界で文脈を区切る(1 セッション 1 タスク) | 古い議論の信号比低下 |

3. **計測点に接続する**: 委譲によってメインから隔離された作業量は、委譲完了時の記録ログに残る。これを「抑制が効いているか」の観測点とする。効果が定量で見えない抑制策は、効いているかを検証できない。
4. **段階導入する**: 集計の自動化・定期レポート化は、手動運用で定型が見えてから入れる。先回りで計測基盤を作り込まない(過剰投資)。

## 判断基準

| 状況 | 抑制する | そのまま |
|---|---|---|
| 出力が結論より大きい | ◯(委譲 or 切り詰め) | |
| 失敗の終了コード・エラーが抑制で失われる | | ◯(保持を優先。診断を壊さない) |
| 入口で全文が必要か不明 | ◯(まず要約、深掘りで全文) | |
| 切り詰めると利用者が明示的に欲した出力が消える | | ◯(明示要求は尊重、抑制をスキップ) |

抑制は「診断・判断に必要な情報まで削る」ところで止める。終了コード・失敗内容・利用者が明示要求した出力は残す。

## アンチパターン

- 「短くせよ」とだけ唱え、発動点も機構も特定しない
- 大量出力を切り詰める際に終了コードや失敗内容まで落とし、後段の失敗検出を壊す
- 利用者が明示的に求めた全文出力まで一律に切り詰める
- 効果を計測せず、抑制が効いているか検証しないまま積み増す
- 計測の自動化を、定型が見える前に作り込む(過剰投資)
- 自分の出力で毎回「これまでの要約」を書き起こし、コンテキスト消費を二重化する

## 旧資産からの継承

旧資産には「テスト出力を末尾 N 行に圧縮」「探索の委譲」「セッション境界の置き方」といった個別の圧縮運用があったが、発動点と機構の対応や計測との接続は明文化されていなかった。本 practice はそれらを「発動点 → 機構 → 計測」の因果として一覧化し、原則のコンテキスト経済を検証可能な運用へ落としたもの。
