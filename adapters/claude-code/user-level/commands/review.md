以下のファイルを簡易レビューする: $ARGUMENTS

重大な問題のみを指摘し、簡潔に報告する。

## 詳細レビューへの切り替え基準

以下に該当する場合は、このコマンドでなく **`code-reviewer` subagent**(7 観点 / 重大度別出力)への委譲を推奨します:

- **変更行数**: 100 行超
- **対象ファイル数**: 5 ファイル超
- **変更の性質**: 設計・API・データ契約の変更

詳細レビューが必要な場合は、明示的に `code-reviewer` subagent を起動するか、[`/review-loop`](./review-loop.md) で反復レビューを使用してください。

## 簡易レビュー観点

- 構文 / 型エラーの懸念
- 明らかなセキュリティ問題(SQL インジェクション / 機密のハードコード等)
- 明らかな誤魔化し(`@ts-ignore` の理由なし / 空 catch / `// あとで直す` 等)
- デッドコード(コメントアウト / 未使用 import)

## 出力

```
## 簡易レビュー結果
- 問題: <count>(重大: <n>)

### 重大(必須修正)
- <file:line> - <問題> - <修正案>

### 軽微 / 提案
- <file:line> - <提案>
```

## 反復レビューが要るとき

上記「詳細レビューへの切り替え基準」に当たる場合は、単発レビューでなく
[`/review-loop`](./review-loop.md)(レビュー→修正→レビューの反復 + 最終ゲート)を使用してください。

## 関連

- subagent: `code-reviewer`(詳細レビュー)
